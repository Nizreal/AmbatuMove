Autentikasi dan penggunaan

Endpoint publik dapat diakses tanpa key. Kirim header X-API-Key untuk API mitra sesuai scope. Gunakan Authorization: Bearer TOKEN untuk data pribadi. Operasi admin memerlukan role admin; save: true pada pembuatan latihan/program memerlukan JWT. Estimasi kalori berbasis MET.

Scope API
catalog:read Latihan, peralatan, kelompok otot, kategori
gyms:read Gym, peralatan, fasilitas
calories:estimate Estimasi dan rekomendasi kalori
planner:preview Pratinjau latihan/program, alternatif

Batas bawaan: 60 request/menit publik, 120 mitra per kelompok rute, dan 5 untuk autentikasi. Gunakan timeout dan backoff untuk 429/503/504.
