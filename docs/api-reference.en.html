Authentication and usage

Public endpoints accept anonymous requests. Send X-API-Key for scoped partner access. Send Authorization: Bearer TOKEN for personal data. Admin operations require the admin role; save: true in workout/program generation requires a JWT. Calorie estimates are MET-based.

Scope API
catalog:read Exercises, equipment, muscle groups, categories
gyms:read Gyms, equipment, facilities
calories:estimate Calorie estimates and recommendations
planner:preview Workout/program previews, alternatives

Defaults: 60 public requests/min, 120 partner requests/min per route group, and 5 for authentication. Use timeouts and backoff on 429/503/504.

Access: Public / X-API-Key

Stateless gross MET estimate. Required duration is rounded up to a whole minute; each returned estimate is recalculated at its recommended (possibly capped) duration.
